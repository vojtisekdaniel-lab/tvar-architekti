# Tvar architekti – web

Scroll animace: černý outline se přetváří mezi 9 kroky (Figma: "Tvar-Architekti – wireframe", stránka CLAUDE).

- `index.html` – aktuální build (statický, otevři v prohlížeči přes lokální server)
- `assets/screens`, `assets/photos` – podklady z návrhu
- `tools/` – skripty, které z tvarů ve Figmě počítají morfování (`morph.py`, `shapes.py`, šablona `tpl.html`)
